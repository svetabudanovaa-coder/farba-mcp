# farba-mcp — каталог farba.md для ИИ-агента SendPulse

Сервер читает публичные страницы farba.md:
- поиск;
- карточку товара: цены на сайте и в магазине, наличие по 5 магазинам, характеристики.

Эти данные он отдаёт ИИ-агенту SendPulse по протоколу MCP. Код сайта не меняется.

## Файлы
| Файл | Что это |
|---|---|
| `server.py` | MCP-сервер: инструменты, авторизация, `/health`, `/selftest` |
| `farba_site.py` | Чтение страниц farba.md. Список магазинов — в начале файла (`STORES`) |
| `render.yaml` | Настройки для автоматического запуска на Render.com |
| `requirements.txt` | Зависимости |
| `agent_prompt.md` | Текст для промпта агента в SendPulse |
| `tests/` | Подставной сайт и сквозные тесты (`python tests/test_e2e.py`) |

## Адреса после запуска
- `https://<имя>.onrender.com/mcp` — адрес для SendPulse.
- `https://<имя>.onrender.com/selftest` — проверка, что сервер правильно понимает сайт. Открывается в обычном браузере; должно быть `"status": "OK"`.

## Если сайт поменял вёрстку
`/selftest` покажет «ПРОБЛЕМА». Правится только файл `farba_site.py`.

## Нагрузка на сайт
- Не больше 3 запросов в секунду.
- Кэш: поиск — 5 минут, карточки — 2 минуты.
- Настраивается переменными `SITE_RPS`, `CACHE_TTL_LIST`, `CACHE_TTL_PRODUCT`.
